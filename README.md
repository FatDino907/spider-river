# Spider-River
A little web-swinging phone game made for River. Original characters and art, fan-made, not affiliated with any comic publisher.
Open index.html in a phone browser. v4: ◀ ▶ to run left or right (stop or turn back anytime), JUMP (tap again to flip), hold up top or SWING to web-swing either way, ZAP bad guys. SUIT UP! spends tokens & comic pages on gear; "Reset Progress" at the bottom of SUIT UP! (or ?reset=1) starts fresh.
Change the hero name in `game.js` (`HERO_NAME`).
