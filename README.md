# Spider-River
A little web-swinging phone game made for River. Original characters and art, fan-made, not affiliated with any comic publisher.
Open index.html in a phone browser. JUMP (tap again for a double-jump flip), hold the screen or SWING to web-swing, tap ZAP for bad guys. v3: tap SUIT UP! to spend tokens & comic pages on new gear (hoodie, headphones, backpack, shades, web gauntlets) and choose mask on, pushed up or off.
Change the hero name in `game.js` (`HERO_NAME`).
